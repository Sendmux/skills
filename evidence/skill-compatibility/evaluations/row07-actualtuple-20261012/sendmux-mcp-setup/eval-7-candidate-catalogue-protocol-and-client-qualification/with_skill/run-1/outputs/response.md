`sendmux-mcp` speaks MCP protocol revisions `2025-11-25` and `2026-07-28` over stdio or Streamable HTTP. Those identify protocol compatibility; package versions identify software releases. The guide references released package `2.1.3`; candidate source declares `2.2.0`, which does not prove publication.

Customers should expect only the tools permitted by their selected surfaces and approved OAuth grant. Released `2.1.3` has 54 tools: 26 Mailbox, 22 Management, 6 Sending. Unpublished candidate source has 65: 36 Mailbox, 23 Management, 6 Sending. A credential-visible subset is not the whole catalogue.

Named clients are documented configuration examples, not automatically certified. Publication status and compatibility with the chosen client require separate verification.
