The setup guide targets `sendmux-mcp` package version **2.1.3**, which speaks MCP protocol revisions **`2025-11-25` and `2026-07-28`** over stdio or Streamable HTTP. The package version identifies the Sendmux software release; the dated protocol revisions identify the MCP communication specifications it supports. Keep both in the compatibility note.

The complete catalogue is **54 tools: 26 Mailbox, 22 Management, and 6 Sending**. A customer should expect the subset allowed by their selected surfaces and approved OAuth grant. Seeing fewer tools after OAuth does not redefine the complete catalogue or automatically indicate a setup failure. For a multi-mailbox grant, use `mailbox_list_granted_mailboxes` first and pass the returned `mailbox_id` when targeting a mailbox.

Clients named in the guide have documented configurations; inclusion does **not** certify compatibility. Verify the chosen client separately: refresh its MCP connection, confirm visible tools match the selected surfaces and grant, and use the relevant harmless `mailbox_get_connection`, `management_get_connection`, or `sending_get_connection` check. Tool discovery alone does not validate the upstream credential; these connection checks send no email.
